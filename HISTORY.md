  - **Bug ditemukan & diperbaiki (dites lewat curl API langsung, bukan cuma baca kode)**:
    1. **Indexing array 2D PL/pgSQL** — seed sempat pakai `pairs uuid[][] := ARRAY[ARRAY[...], ...]` untuk pasangan cabang/staf; ternyata `pairs[i]` pada array 2D asli di Postgres mengembalikan `NULL` (bukan "baris ke-i" seperti bahasa lain), menyebabkan error `null value in column "branch_id" violates not-null constraint`. Fix: ganti jadi dua array 1D paralel (`branch_ids uuid[]`, `staff_ids uuid[]`) diindeks dengan indeks yang sama.
    2. **Cast enum PL/pgSQL** — variabel `payment_status` bertipe `text` dimasukkan langsung ke kolom bertipe `billing.payment_status` → error `column "status" is of type billing.payment_status but expression is of type text`. Fix: cast eksplisit `payment_status::billing.payment_status` saat insert.
    3. **Kelas Tailwind dinamis tidak ter-generate** — `MonthCalendar.vue` awalnya membentuk nama class lewat template literal (`` `bg-${warna}-100` ``); JIT scanner Tailwind butuh string literal utuh saat build, jadi class hasil template literal tidak pernah masuk CSS akhir (chip status tampil transparan). Fix: peta statis `STATUS_CHIP_CLASS` yang mendaftarkan nama class lengkap untuk tiap 7 status reservasi.
    4. **Cache key `useFetch` bentrok** — halaman Reservasi memanggil `useApiFetch('/reservations')` dua kali (list & kalender) dengan argumen identik; Nuxt men-generate cache key default yang sama untuk keduanya sehingga kedua ref jadi alias satu sama lain (update salah satu menimpa yang lain diam-diam). Fix: `useApiFetch` menerima parameter `key` opsional, dipakai eksplisit (`'reservations-calendar'`) untuk fetch kalender.
